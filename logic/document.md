一、 项目定位
产品名称：Concept Music (暂定)

设计语言：极简、深色系、沉浸式、大圆角、微拟物。

核心目标：提供一个纯粹的音乐欣赏环境，弱化社交，强化封面视觉与流线型操作。

   交互：点击进入搜索建议页。

   个性化 Radio 模块：

   功能：点击直接进入流派/心情选择，中间有动态波形图。

   交互：支持左右切换不同流派的预览。

   推荐频道 (Recommended Channels)：

   布局：RecyclerView 横向滚动。

   元素：卡片阴影、左上角“频道名”、左下角“订阅数”、封面图（带有轻微的渐变遮罩）。

   新歌速递 (New Releases)：

   布局：嵌套列表，包含 3-5 个大横向卡片。

2. 播放页 (Player Screen) —— 核心开发重难点
   背景视觉：

逻辑：实时提取当前歌曲封面的主色调，使用 RenderScript 或 Toolkit 进行 80dp 半径的高斯模糊。

遮罩：背景上层覆盖 20% 透明度的黑色遮罩，确保文字清晰。

黑胶/唱片组件：

结构：中心圆形封面 + 唱针（可选）+ 外部圆环阴影。

动画：歌曲播放时 rotate 动画（360度/20s），暂停时平滑停止。

交互控件：

进度条 (SeekBar)：自定义样式，滑块（Thumb）在非触摸状态下隐藏。

控制按钮：使用 Selector 实现点击缩放反馈。

评论预览：底部向上滑动可呼出简易评论面板（220 条评论提示）。

   资产入口 (Functional Grid)：

包含“收藏”、“最近播放”、“本地”、“云盘”、“导入音乐”等入口。

显示逻辑：除“导入音乐”外，每个卡片右下角实时显示歌曲数量，“导入音乐”不显示数字。

# 酷狗概念版仿制项目（Android）详细需求文档 (PRD)

## 1. 项目概述
* **项目名称**：Concept Music (仿酷狗概念版)
* **开发环境**：Android Studio (Chipmunk 或更高版本)
* **编程语言**：Kotlin / Java
* **设计风格**：极简主义、深色模式 (Dark Mode)、沉浸式封面视觉、大圆角卡片化布局。

---

## 2. 页面详细需求

### 2.1 发现页 (Discovery Screen)
* **顶部栏**：
    * **搜索框**：半透明胶囊设计，支持动态 Hint 滚动。
    * **设置入口**：右上角图标，进入系统/偏好设置。
* **个性化 Radio 区**：
    * 横向滑动卡片，展示不同流派（流行、摇滚、电音等）。
    * 带有“播放”小图标，点击即刻播放该频道的种子音乐。
* **推荐频道 (Recommended Channels)**：
    * 使用 `RecyclerView` 配合 `SnapHelper` 实现横向居中滑动。
    * **卡片设计**：大圆角（24dp），底部显示订阅人数，左上角显示频道标签。
* **新歌速递 (New Releases)**：
    * 纵向列表或大型横向卡片，突出展示专辑封面。

### 2.2 播放界面 (Player Screen)
* **沉浸式背景**：
    * **动态取色**：使用 `Palette API` 从当前歌曲封面提取 2-3 种主色调。
    * **高斯模糊**：背景进行 80% 程度的模糊处理，形成流光溢彩效果。
* **黑胶/封面旋转组件**：
    * 居中展示圆形封面，播放时以 20s/圈的速度匀速旋转。
    * 暂停时旋转平滑停止，而非瞬间卡住。
* **交互逻辑**：
    * **进度控制**：线性 SeekBar，实时显示已播放时间与总时长。
    * **播放控制**：中间大播放/暂停键，两侧为上一曲/下一曲。
    * **歌词显示**：默认展示单句精简歌词，点击封面切换至全屏滚动歌词。

### 2.3 个人中心 (Profile Screen)
* **用户概览**：展示头像、昵称、VIP 等级勋章。
* **功能矩阵卡片**：
    * 包含“收藏”、“最近”、“本地”、“云盘”、“导入音乐”等入口。
    * 实时显示对应类目的歌曲统计数量（“导入音乐”除外，不显示数字）。
* **歌单管理**：
    * “我创建的歌单”列表。
    * 支持“导入外部歌单”功能（弹出 Dialog 输入链接或识别剪贴板）。
* **UI 小助手**：右下角常驻 Lottie 动态看板娘，带随机文案气泡。

---

## 3. 技术栈建议 (Tech Stack)

| 维度 | 推荐方案 |
| :--- | :--- |
| **架构模式** | MVVM (ViewModel + Repository + Flow) |
| **音频引擎** | Jetpack Media3 (ExoPlayer) |
| **UI 框架** | Jetpack Compose (推荐) 或 XML (ConstraintLayout) |
| **图片加载** | Coil (对 Compose 支持极佳且性能优越) |
| **本地存储** | Room Database (存储歌单、历史记录) |
| **依赖注入** | Hilt (简化对象管理) |

---

## 4. 关键交互与视觉规范

### 4.1 视觉参数
* **全局圆角**：CardView / Image = 24dp。
* **主背景色**：`#121214` (非纯黑，带有深灰色调以保护视力)。
* **字体**：主标题 18sp (Bold)，副标题 13sp (Medium)。

### 4.2 动画规范
* **转场动画**：点击首页歌曲进入播放页时，封面应使用 **Shared Element Transition** 平滑放大。
* **反馈动画**：按钮点击时带有轻微的缩放（Scale）和震动反馈。

---

## 5. 开发路线图 (Roadmap)

1.  **阶段 1**：环境搭建与基础播放功能（ExoPlayer 服务端实现）。
2.  **阶段 2**：播放页静态 UI 与动态取色算法开发。
3.  **阶段 3**：发现页多布局适配与列表数据填充。
4.  **阶段 4**：本地存储逻辑（Room）与个人中心开发。
5.  **阶段 5**：全局动效优化与性能调优。
