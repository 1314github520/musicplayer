# 🎵 Android 音乐播放器

一个基于 Java 开发的轻量级 Android 音乐播放器项目，专注于流畅播放体验、歌词同步以及高效的网络请求处理。

---

## ✨ 功能特性

- 🎧 本地与在线音乐播放
- 📜 歌词（LRC）搜索与解析
- ⚡ 基于 OkHttp 的高性能网络请求
- 🧠 使用 LruCache 实现内存缓存
- 🎨 简洁清爽的界面设计
- 🔄 异步数据处理

---

---

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/1314github520/musicplayer.git
```

### 2. 使用 Android Studio 打开

- 打开 **Android Studio**
- 点击 **Open**
- 选择项目目录

### 3. 运行项目

- 连接 Android 设备或启动模拟器
- 点击运行按钮 ▶

---

## 🔧 核心技术

- **Java**
- **Android SDK**
- **OkHttp**（网络请求）
- **Gson**（JSON 解析）
- **LruCache**（内存缓存）

---

## 📡 歌词服务（LrcLibService）

主要功能：

- 歌词搜索（调用 API）
- JSON 数据解析
- 结果缓存优化
- 异步回调处理
